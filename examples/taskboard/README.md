# Taskboard

Учебный CLI-список задач без внешних зависимостей. Данные хранятся в JSON.

```sh
python3 app.py add 'Купить молоко'
python3 app.py add 'Написать тесты'
python3 app.py done 1
python3 app.py list
python3 -m unittest discover -s tests -v
```

Глобальный параметр `--store PATH` задаётся перед командой и позволяет выбрать
отдельный JSON-файл. Номер задачи не переиспользуется; повторное завершение
допустимо. Пустое название и неизвестный номер завершают команду с ошибкой.

Это исходная версия для экспериментов. Прогресс harness сохраняется отдельно.
