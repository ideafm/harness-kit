Добавь фильтрацию списка задач в учебном Taskboard.

CLI `list --status all|open|done`; по умолчанию all, чтобы сохранить прежнее
поведение. open возвращает только незавершённые, done — только завершённые.
Функция list_tasks(store, status="all") должна поддерживать те же режимы.
Порядок и исходный JSON-файл не меняются при фильтрации. Для неизвестного
статуса функция выбрасывает ValueError, CLI завершается ненулевым кодом.

Добавь тесты пустого списка, смешанного списка, каждого фильтра, неизвестного
статуса и совместимости вызова list без параметра. Обнови README с примерами.
Разрешённые изменения: app.py, tests/test_app.py, README.md. Новых зависимостей,
скрытых конфигов, сети и секретов не требуется. Существующие тесты не ослабляй.
Готово: проверки проекта зелёные и CLI правильно фильтрует список.

Тестовые данные создавай как отдельные временные JSON-файлы в текущей рабочей
папке с уникальным именем, как в существующих тестах. Удаление каталогов
ограничено текущим sandbox; fixture не должна требовать его или записи в /tmp.
