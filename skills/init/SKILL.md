Подключи рельсы tw к проекту в текущей рабочей директории. Пустая папка или новый проект — нормальный случай: рельсы подключаются до того, как появится код.

1. Корень проекта: ближайшая вверх директория с `package.json` или `.git`; если их нет — текущая директория. Ничего не создавай и не предлагай создать: ни `package.json`, ни `git init`, ни каркас проекта.
2. Команда тестов: если в `package.json` есть скрипт `test` (не заглушка `npm init`) — `npm test`. Если тестов нет — не спрашивай и поле `test` не пиши: hooks сами возьмут `npm test`, когда скрипт появится.
3. Создай `.claude/tw.json`:

```json
{
  "test": "<команда тестов, если определена>"
}
```

Без команды тестов — `{}`. Если файл уже есть — покажи его и спроси, перезаписывать ли.

4. Добавь строку `.claude/tw-state/` в `.gitignore` корня; нет файла — создай.
5. Сообщи одной строкой: что создано, какая команда тестов (или «появится вместе со скриптом test»), и что рельсы заработают после `/clear` или новой сессии. Дальше задачу не начинай.
