# Задача в бэклог

Каждое своё сообщение пользователю на этом этапе начинай с метки отдельной строкой: `**[tw · бэклог]**`.

Записать задачу должно стоить секунды, иначе мысли теряются. Уточнять будет `tw:spec`, когда задачу возьмут в работу: вопросы сейчас тратятся на задачи, которые могут и не понадобиться.

**Код не меняешь.** Создаёшь только `docs/backlog/B-NNN.md`.

## Процесс

1. Номер: максимальный `B-NNN` в `docs/backlog/` плюс один; папки нет — `B-001`.
2. Посмотри в коде, где это живёт (1–3 поиска, не больше): заполни «Где». Не нашёл — «не искали».
3. Похожая задача уже есть — не создавай дубль: скажи номер и спроси, дописать ли туда.
4. Вопрос — только если непонятно, о чём задача вообще. Один. Всё остальное — в «Открытые вопросы» для `tw:spec`.
5. Запиши файл по шаблону. Приоритет и размер оцени сам и пометь `[оценка агента]`, если пользователь их не назвал.
6. Ответ одной-двумя строками: номер, заголовок, приоритет. Предложи: «Взять сейчас — скажи, оформлю через `tw:spec`».

## Шаблон

```markdown
# B-001 · <что должно стать иначе, языком результата>

- **Статус:** входящая
- **Приоритет:** P2 · **Размер:** M · **Категория:** продукт
- **Источник:** человек ГГГГ-ММ-ДД
- **Где:** `путь/файл.ts`
- **Зачем:** <слова пользователя, без пересказа>
- **Готово, когда:** <если сказано; иначе «уточнить в спеке»>
- **Открытые вопросы:** <развилки для tw:spec>
- **Спека:** — · **План:** — · **Ветка:** —

## Журнал

- ГГГГ-ММ-ДД · создана
```

- Статус: `входящая` → `готова` (спека и план утверждены) → `в работе` → `на приёмке` / `застряла: <почему>` → `принята` / `отклонена: <почему>`.
- Приоритет: P0 — чинить сейчас (уязвимость, которую можно использовать, сломанный прод); P1 — потеря данных, денег, доступа или сломанный сценарий; P2 — риск или заметное неудобство; P3 — гигиена.
- Размер: S — до 2 ч, M — до дня, L — больше дня.
- Каждая смена статуса — строка в «Журнал».

## Красные флаги — остановись

- Задаёшь второй вопрос или пишешь спеку.
- Правишь что-то, кроме `docs/backlog/`.
- Переписал слова пользователя в «Зачем» своими.
