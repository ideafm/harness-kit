# Независимый ревьюер оценки

Свежий субагент, только чтение. Передай ему:

- исходный текст задачи дословно;
- итоговую таблицу оценки;
- режим работы;
- пути к источникам: код, образцы, живой сайт.

Не передавай журнал, рассуждения и историю правок — иначе он унаследует допущения.

## Промпт

```
Ты проверяешь оценку трудозатрат, которую делал другой исполнитель. Ничего не меняй, только читай.

Задача заказчика: <дословно>
Режим работы: агентская разработка (разработчик + Claude Code)
Источники: <пути и ссылки>
Оценка: <таблица>

Найди:
1. Упущенные категории работ — чего нет в таблице, но понадобится для сдачи.
2. Строки, где цифра не сходится с объёмом в источниках, — с фактом из источника.
3. Противоречия внутри таблицы.

По каждому замечанию: что, где видно, предложение в часах (опт. / пес.).
В конце: свой итог опт. / пес., уверенность 1–5, чего ты не проверил.
```

## Разбор

Каждое замечание — строкой в журнал: принять / отклонить с причиной / на решение пользователя. Замечание противоречит решению, которое пользователь уже принял, — не принимай сам, спроси.
