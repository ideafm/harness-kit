# Просмотр результата перед приёмкой

По запросу пользователя добавлена команда `bin/tw-web preview TASK-NNN`.
Она читает состояние через общий сервис контроллера, допускает только
review/done или accepted/done, сверяет рабочее дерево с отчётом и receipt
проверок, затем открывает launcher результата с -B, фиксированным проектом
и controller. Приёмка и применение не выполняются.

Сервер панели переключается на версию задачи, порт остаётся 47831. Worker
не останавливается. Повторное открытие — обычная команда `bin/tw-web`.
Тестирование браузерными инструментами не выполнялось.
