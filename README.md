# tw-web

Итерация проектов TASK-003: sidebar показывает проекты из GET /api/v1/projects. Создание, управление, события и артефакты используют /api/v1/projects/{id}; session общий. Возврат восстанавливается через ?project={id}&task={n}. Подключение открывает предоставленную контроллером форму отдельной страницей; список обновляется при возврате и вручную.

Pending сохраняются отдельно для каждого проекта. Старые слоты без project id остаются нетронутыми. После переключения или reload команды автоматически не повторяются; известные операции восстанавливаются через GET по явному действию. Индикатор каждой задачи отражает текущий этап, а не процент. «Принято человеком» отличается от ожидания приёмки.

[Спецификация проектов](docs/specs/2026-11-02-projects.md), [план проектов](docs/plans/2026-11-02-projects.md). Проверки текущего diff агентом не запускались: TypeScript, interaction tests, production build и Python unittest переданы контроллеру. TASK-002 не принимается и не применяется этой итерацией.

Русская локальная панель автономных задач: Next App Router, TypeScript, Tailwind v4 и официальные shadcn-компоненты. Реальные задачи и счётчики, решения, команды, артефакты и история поступают через /api/v1 внешнего native gateway.

## Доставка

Static export настроен в next.config.mjs, рабочий каталог сборки build-next. Зависимости и lockfile подготовлены контроллером; агент не устанавливает пакеты и не меняет версии. Системные шрифты, без внешних скачиваний.

Контроллер связывает проверенный экспорт с реальным API после независимых проверок и receipt. Python server/launcher и 15 исходных тестов сохранены. Старый bin/tw-web сам по себе пока показывает исходную стартовую страницу. Команда tw-web, loopback 127.0.0.1:47831 и lifecycle не изменены.

## Управление

Создание auto/approve-plan, start/pause/resume и ответы используют CSRF, revision, идемпотентность и GET операции до подтверждения успеха. Человеческие решения открывают отдельный origin контроллера: http://127.0.0.1:47832/confirm. Финальные замечания и причины вводятся там. Открытие ссылки не считается успехом. Приёмка не применяет diff; применение и preview недоступны.

## Проверки

Агент не запускал Node, npm, tsc, Vitest, Next или независимые проверки. Контроллер выполняет Python unittest discover, tsc --noEmit, vitest run и next build --webpack в подготовленной копии, связывая receipt с хэшами исходников и toolchain. До receipt сборка не подтверждена. Browser QA не выполнялся.

Добавлены тесты с jsdom и подставленным transport: пустые состояния, граница подтверждения, лимиты UTF-8, CSRF/revision/идемпотентность и ожидание операции. Исходные Python-тесты не изменены.

[Спецификация](docs/specs/2026-11-02-next-redesign.md), [план](docs/plans/2026-11-02-next-redesign.md), [операторский контракт](docs/specs/2026-11-02-operator-contract.md), [сессия](docs/sessions.md).

Это самостоятельная итерация поверх baseline, без предположения о принятом TASK-001. Коммиты, интеграция, автоматическое применение и обновление контроллера не выполняются.

## Интерфейс «Фокус» · TASK-004

Проекты, компактный список и карточка решения; поиск, фильтры и страницы. Полный исходный запрос, план, изменения, проверки, ревью и история открываются по кнопкам в модалках. Worker открывает сведения о процессе и готовую команду наблюдения; команда не запускается браузером. Preview доступен только по предоставленной loopback-ссылке.

Человеческие решения выполняются только встроенными trusted формами контроллера. Отсутствие формы или csrf означает недоступность управления; отдельная страница не используется как обход. Приёмка не применяет diff. Спецификация и план: docs/specs/2026-11-03-task-004-ui.md, docs/plans/2026-11-03-task-004-ui.md. TypeScript/build/interaction/Python и визуальные проверки переданы контроллеру; агент не подтверждает их прохождение.
