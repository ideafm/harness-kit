# TASK-005: UX приёмки

Сохранить минималистичный дизайн A и палитру B. Перед решениями показать «Посмотреть результат» из task.preview.url через существующую loopbackUrl; при отсутствии поддерживаемого адреса явно сообщить о недоступности.

«Принять», «Доработать», «Отклонить» используют только существующие trusted widgets для accept_result, request_changes, reject_result. Объяснить последствия: коммит и merge в основную копию, продолжение рабочей копии, удаление предпросмотра без изменения основной версии соответственно. Сохранить allowed_actions, CSRF, project, pending/busy и проверки сообщений; подтверждение остаётся в контроллере.

Task получает optional integration {source_commit,commit,branch}, integration_error, commit_error. Для accepted приоритет: integration_error — «Принято, применение остановлено»; commit_error — «Принято, коммит не создан»; полная integration — «Принято и применено»; иначе — «Принято, применение не подтверждено». Единое представление используется карточкой, списком и прогрессом. Обе ошибки отображаются безопасным текстом; предложить передать причины оператору для устранения в контроллере. Короткий commit (первые восемь символов) и ветка доступны в существующем диалоге.

Допущения: пустые строки ошибок не считаются ошибкой; неполная integration не подтверждает применение; неизвестные stage/state остаются неизвестными. Базу main с TASK-004 предоставляет контроллер, скрытые Git-данные не читаются. Тексты iframe задаёт контроллер. Backend, зависимости и защитные границы не меняются. Агент не выполняет commit, merge или accept; результат принимает человек.
