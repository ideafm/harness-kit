# Совместимость проверки MCP перед запуском Tw

Перед редизайном launcher блокирует запуск: mcp_servers={tw=...} сливается
с пользовательскими серверами, а codex mcp list не поддерживает exec-флаг
--ignore-user-config. Проверка видит context7/playwright и останавливается.

Исправление: перечислить только имена включённых серверов через существующую
проверку CLI, добавить в конкретную команду запуска enabled=false для всех
посторонних имён и заново проверить конфигурацию. В интерактивном режиме эти
overrides передаются и запускаемой команде. В headless они нужны только
для mcp list: exec обязательно получает --ignore-user-config, поэтому
пользовательские серверы в него вообще не попадают. Не добавлять туда пустые
описания отключённых серверов: без транспорта CLI их отвергает. Пользовательские
файлы не читать напрямую и не менять. При отсутствии tw, ошибке или сохранении
посторонних серверов отказать в запуске. Песочница и canary остаются обязательны.
Не запускать модель до успешной проверки. Проверять явные параметры запуска
с учётом разницы режимов. Необычные имена, не допускающие безопасный dotted
override, блокируют запуск. Число проверок ограничено двумя.

Источник: официальная документация CLI https://learn.chatgpt.com/docs/cli/reference
и Context7 /openai/codex: --ignore-user-config относится к exec, mcp list
перечисляет настроенные серверы. Реальное воспроизведение показало слияние.
