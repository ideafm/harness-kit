# Явные зависимости задач

depends_on при создании — до 100 различных существующих номеров задач текущего проекта. Зависимости неизменяемы в этом первом этапе: новые ссылки только на уже существующие задачи, поэтому самоссылки и циклы не создаются. Невалидные ссылки отклоняются до записи задачи.

Готовность требует accepted и integration без integration_error/auto_apply_error, незавершённой интеграции или auto_apply_pending. Успешное ревью само по себе недостаточно. Удалённая/отклонённая/ожидающая человека предпосылка оставляет зависимую задачу в ожидании. Рабочие независимые задачи продолжаются. Проверка повторяется при фактическом старте внутри транзакции; provenance интеграций сохраняется. Запущенная задача продолжает работу с уже полученной основой.

В UI поле «Зависит от задач» с номерами через запятую и причина ожидания в карточке/списке. Текущий порядок очереди не меняется. Оркестратор управляет входящими задачами и зависимостями; поиск новых проблем — отдельная опциональная команда.
