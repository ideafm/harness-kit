# Этап 2.1b: единое подключение

При первом tw из обычного Git-проекта подключать его существующим connect:
редактируемые --check/--model и безопасное определение Python unittest.
Для неизвестного check отказать до запуска модели с инструкцией tw init --check.
Повторное подключение сохраняет задачи, check/model и собственные setup-файлы.
Незнакомый или изменённый skill не читать/перезаписывать.

После успешного подключения CLI регистрирует проект в панели tw-web, если она
подключена, иначе в локальном реестре. Ошибку регистрации не скрывать.
Все пути проекта проверять до resolve: скрытые пути, переходы и ссылки
запрещены. Не запускать сервисы или задачи и не выдавать новые права.
