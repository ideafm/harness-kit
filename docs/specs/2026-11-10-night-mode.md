# Ночной режим и зависимости — следующий отдельный этап

Статус: согласованное направление, реализация и включение не выполняются этим проходом.

## Поведение

- Ночной режим явно включается человеком для проекта/запуска. По умолчанию остаётся ручная приёмка.
- После проверок и независимого разрешающего ревью контроллер проверяет точную версию результата, интегрирует её и проверяет объединённую основную версию. Ошибка публикации сохраняет последнюю успешную панель.
- Вопрос, конфликт, ошибка проверок или потребность в ручной приёмке останавливают только затронутую задачу. Планировщик продолжает готовые независимые задачи.
- При постановке задачи можно указать depends_on — список задач того же проекта. Контроллер отвергает отсутствующие зависимости, самоссылки и циклы. По умолчанию задача независима.
- Зависимая задача готова только после успешного применения результатов всех предпосылок. Review/done или accepted с integration_error недостаточны. Неявное наследование только по соседству в очереди запрещено.
- Новая задача готовится от актуальной основной версии после применения предпосылок. Фиксируются base и подтверждённые результаты зависимостей.
- Для заблокированной зависимости UI показывает конкретные номера и причину. Удаление предпосылки не превращает зависимую задачу в независимую.
- Существующие ограничения sandbox, квоты, доступа к секретам, критерии риска и точные версии планов/результатов сохраняются. Политика автоматической приёмки контроллерная; агент не получает возможность выдавать себя за человека.

## Приёмочные сценарии

1. A задаёт вопрос, независимая B выполняется, C с depends_on=[A] ждёт. После ответа и успешного применения A задача C становится готовой.
2. Конфликт применения A не останавливает B и не разрешает C.
3. Перезапуск не повторяет интеграцию и не теряет причины ожидания/зависимости.
4. Недостаточный лимит одного backend не останавливает готовую независимую задачу другого backend, если её собственный Guard разрешает запуск.
5. Автопринятие не включено — прежний ручной сценарий работает без изменений.
