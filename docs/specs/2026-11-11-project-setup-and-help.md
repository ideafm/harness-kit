# Пояснения просмотра и подключение проекта

## Запрос

Пояснить дополнительные действия просмотра. Проверить доступность tw из PATH.
Упростить указание тестов и проработать отдельную команду запуска проекта
(Nuxt, Next, npm run dev, Docker Compose).

## Пояснения

Показывать короткий текст непосредственно под каждой кнопкой внутри раскрываемого
раздела; текст доступен без hover. Проверенная версия — сохранённый результат
последних успешных проверок. Рабочая версия — сборка текущих файлов задачи,
которые могут ещё не пройти проверки. Повтор подготовки сохраняет выбранный
режим; повтор прежней операции относится к запросу с неизвестным исходом.
Пояснить перемещение задачи в корзину с сохранением истории и файлов.
Существующие названия кнопок, проверки прав и действия не менять.

## Подключение и запуск

tw уже установлен как launcher в /opt/homebrew/bin, доступен в PATH.
Команда проверок и команда запуска — разные настройки. init не должен запускать
приложение, устанавливать пакеты или открывать защищённые ресурсы.
Для package.json с непустым scripts.test автоматически выбирать npm test при
первом init; при явном другом packageManager не угадывать команду. Обычная
Python unittest-конвенция сохраняется. При неоднозначности спрашивать команду,
а не подставлять успешную пустую проверку. Повторный init не меняет настройки.

tw configure показывает команды; --check задаёт проверку, --run сохраняет
команду запуска, --clear-run удаляет только команду запуска. Изменение check/run
доступно операторскому CLI, не агентскому MCP. Обновление защищено блокировками
runner и интеграции. Настройка не исполняет команды. run пока является сохранённой
настройкой для будущего runtime-адаптера, и вывод CLI явно сообщает об этом.
Целевая версия запуска остаётся вопросом пользователю; серверы не запускаются.
Для произвольного dev-server нужны профиль изоляции, loopback-порт, управление
процессом и понятный статус. Docker Compose требует отдельного проверенного адаптера;
нельзя считать произвольный compose-файл безопасным или запускать его без изоляции.
