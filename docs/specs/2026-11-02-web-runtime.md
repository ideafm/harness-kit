# Контроллер веб-панели и frontend toolchain

Пользователь разрешил продолжить показанный план TASK-002: нормальная панель
Next.js/shadcn с прозрачными ожиданиями и кнопками. Утверждение относится к
версии 937bd1c3309b52142fc1b9c687a11221b28de69e817439572298ac1ffe13cd58.
Это не приёмка результата и не разрешение на коммит/чтение пользовательских секретов.

## Операторские операции

Контроллер предоставляет версионированные статусы, control/allowed_actions,
артефакты, события, идемпотентные операции. Идемпотентность и изменение состояния
фиксируются одной SQLite-транзакцией с savepoints в общих операциях Store.
Повторный ключ с другим payload/precondition — конфликт. Ошибки прозрачны.
Состояния и полномочия не определяются frontend. Агентский MCP не расширяется.

Панель слушает 127.0.0.1:47831. Операторское подтверждение для approve/revise,
accept/request-changes/reject обслуживается отдельным доверенным origin
127.0.0.1:47832. Frontend открывает его кнопкой; действие выполняется только
после отправки формы пользователем. Одноразовый токен привязан к действию,
версии и revision, имеет срок действия и недоступен JavaScript другого origin.
Само открытие ссылки ничего не меняет. Текст формы экранируется; строгие
Host/Origin, CSRF и отсутствие CORS сохраняются. Непроверенная UI-сборка
может показывать данные, но не получает операторских токенов принятия.

Остальные действия доступны как ограниченный same-origin API с CSRF и ключом
идемпотентности, как в существующем агентском MCP: submit/start/pause/resume/answer.
Ответ не выдаёт grants. Применение/rollback и коммиты в этот проход не входят.
Показывается точная причина недоступности применения.

## Toolchain и сборка

Node используется из видимого Homebrew runtime, npm запускается с пустыми
явными user/globalconfig, отдельным cache, без install scripts и без чтения
пользовательских env/npm-конфигов. Зависимости фиксируются lockfile и hash tree
в принадлежащем контроллеру состоянии. Установка — действие контроллера;
сеть агента закрыта. Agent workspace получает исходные компоненты shadcn и
манифесты, но не изменяемое дерево зависимостей и не новый доступ наружу.

Проверки Node работают в отдельной сборочной копии контроллера: runtime и
dependency tree read-only, source immutable относительно task workspace,
scratch writable, сеть закрыта. Генерируемые служебные файлы принадлежат
только scratch; исходные env/hidden/keys туда не копируются. Canary проверяет
запрет чтения наружу, изменение runtime/deps, пользовательских скрытых canary,
сеть и дочерние процессы. Провал проверки блокирует сборку, fallback нет.
Receipt связывает source digest, runtime/deps/lock hashes и результаты
Python unittest, tsc, interaction tests, next build. Следы сборки не входят
в diff исходников. Статический export раздаётся только по проверенному manifest.

UI и планирование/реализация остаются в TASK-002; изменения контроллера ведутся
отдельно в harness-kit. Работающий worker не подменяется в ходе этапа.
