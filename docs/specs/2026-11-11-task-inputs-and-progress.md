# Вложения и понятное исполнение

В форме создания задачи добавить выбор, перетаскивание и вставку изображений,
список файлов с удалением, размером и ошибками. Первая версия: PNG/JPEG/WebP,
UTF-8 TXT/MD/LOG/JSON/CSV. До 5 файлов, 2 МиБ каждый, 8 МиБ суммарно.
Файлы предварительно загружаются в project-scoped immutable хранилище контроллера;
создание задачи передаёт ID. Повтор создания сохраняет прежние ID и ключ операции.
Лимит хранилища проекта 100 МиБ. Имена — подписи, не пути. Проверять формат,
размер, hash, ссылки и принадлежность проекту. SVG/HTML/исполняемые файлы запрещены.
Скачивание только через scoped API, без выполнения HTML. Вложения не становятся
изменениями проекта и не расширяют доступ агента. Текст передаётся как недоверенный
контекст, изображения — нативному image input Codex. Для Gemini с изображениями
явно остановить задачу с объяснением, если multimodal контракт не подтверждён.

В карточке показывать текущую работу, длительность текущей попытки, её номер,
последнюю активность, причину ожидания и следующий шаг. Использовать события и
метаданные логов контроллера; не показывать сырой вывод модели как достоверный статус.
Не обещать ETA, не выдавать тишину за зависание. Отделить ожидание человека/лимита/
зависимости от активной работы. Не изменять состояние задач ради отображения.

Проверить безопасность/изоляцию вложений, повторы, соответствие контекста,
ожидания и попытки; frontend/typecheck/build и браузер. По ранее полученному
поручению сохранять изменения коммитом и обновлять проверенную панель.
