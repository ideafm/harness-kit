# Учебный проект для harness

**Цель:** иметь постоянный небольшой проект, на котором можно запускать задачи,
смотреть документы и diff, принимать результат, применять его и откатывать опыт.

**Результат:** шаблон CLI-списка задач на Python без зависимостей; отдельный
репозиторий в `lab/taskboard`; сценарии и команды подготовки, запуска, проверки,
применения и сброса. Каждый сброс архивирует предыдущий экземпляр целиком.

**Готово, когда:**

- Базовые тесты проекта зелёные, первая задача меняет наблюдаемое поведение CLI.
- Настоящий Codex проходит план, исполнение, проверки и ревью в рабочей копии.
- Исходная копия не меняется до явной приёмки и отдельной команды применения.
- Применение ограничено учебным экземпляром, проверяет baseline, статус и diff.
- Сброс сохраняет историю и логи, восстанавливает чистую исходную версию.
- Есть инструкции для status/show, вопросов, паузы и повторного запуска.
- Защита harness не ослабляется; проверки проекта запускаются в sandbox.

**Не трогаем:** реальные пользовательские проекты, глобальные настройки,
старую реализацию Claude, секреты и SSH. Коммиты основного harness не создаём.

**Допущения:** [допущение] терминальный список задач достаточно мал для быстрых
прогонов и допускает дальнейшие сценарии. Первый запуск использует gpt-6.1-sol.
Начальный синтетический коммит учебного проекта требует разрешения пользователя.
