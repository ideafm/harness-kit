# TASK-004: выбран A, палитра B

Пользователь выбрал композицию A «Фокус», затем уточнил цвета B: холодные
светло-серые поверхности, белые карточки, приглушённый синий акцент #466d91.
Он прямо поручил реализацию. Исходный запрос задачи доступен по кнопке в модалке.
Worker открывает реальное состояние и копируемую безопасно quoted команду
наблюдения за конкретной задачей/проектом. Команда пока наблюдает этапы и
события, не обещает интерактивное общение с ephemeral-процессом.

Компоненты shadcn сохраняются. Иконки своих SVG; этапы компактными точками с
hover/focus подсказками. Все дополнительные документы по запросу в модалках.
Основной экран объясняет текущее состояние, что человеку проверить/сделать.
Подтверждения выполняются встроенной формой внешнего контроллера другого
origin: одна реальная кнопка, POST с одноразовым токеном, версией и revision.
Frontend не получает полномочия приёмки и не открывает отдельную страницу.

Внешний контроллер добавляет watch/observation metadata и embedded widgets;
изменения tw-web выполняет Tw в изолированной копии. После обновления конкретного
плана сверить соответствие выбору A+B и последним замечаниям, использовать явное
поручение пользователя на эту реализацию; результат не принимать за человека.

## Очистка завершённого ожидания

После автоматического выхода из rate_limited удалять текущие reason/retry_at,
сохраняя причину и срок в истории событий. Для review/done и accepted API
не показывает поля ожидания, оставшиеся от старых версий runner. Иначе готовая
задача ошибочно выглядит остановленной. Регрессия: лимит → сброс → check →
review/done, без ручного запуска и без устаревшей причины на карточке.
