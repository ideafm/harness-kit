## Доработка по Browser QA

Полная фактическая сводка сохраняется безопасным текстом в закрытом details. Отсутствие дополнительных данных описывается внутри подробностей. Контекст показывает достоверное состояние, реальную причину и вопрос при наличии, существующие действия; review/done обозначает ожидание приёмки. История событий полностью доступна в отдельном раскрытии без изменения EventList и API. Для review/done начальная вкладка — «Проверки», если есть артефакт checks, иначе «Ревью» при наличии review, иначе история.

Большой ряд этапов получает короткие подписи; компактный сохраняет точки и доступные описания. При новом выборе задачи из URL или worker очередь открывает её страницу, если задача входит в текущую выборку. Последующие обновления не меняют вручную выбранную страницу, поиск и фильтры сохраняются. Визуальный заголовок убирает начальный Markdown-маркер заголовка; полный запрос остаётся исходным текстом.
