# Публикация объединённой панели

Приёмка TASK-012 не отменила TASK-013 в Git/SQLite, но опубликовала старый task export. Публиковать можно только receipt с успешными checks и digest актуального frontend основной копии. При несовпадении контроллер собирает объединённую версию в integrated-build внутри состояния принятой задачи. Ошибка сохраняет предыдущий deployment. Task receipt не изменяется. Проверка и публикация выполняются под git-results.lock. Для monorepo учитывается path_scope. Контроллер и idle worker перезапускаются по явному поручению пользователя, реальные задачи не принимаются автоматически.
