# Доступность запуска

Во время работы задачи действие start недоступно. Для queued оно доступно
только при остановленном worker; при работающем или запускающемся worker
задача уже обслуживается очередью. API отклоняет повторный start с новым ключом,
а повтор прежнего ключа возвращает сохранённый результат без нового запуска.
Frontend использует allowed_actions; текущая сборка скрывает недоступные кнопки.
