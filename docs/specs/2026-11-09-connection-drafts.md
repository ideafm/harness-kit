# Черновики при потере соединения

При временной ошибке refresh сохранять последние control/session и DOM trusted iframe выбранной задачи. Отдельный флаг блокирует отправку обычных команд, повтор pending и взаимодействие с iframe до успешного обновления всех данных. Не менять ключ iframe на сбое/восстановлении прежней revision. При смене проекта/задачи или revision действуют прежние правила очистки. Ошибка показывается пользователю, создание и project view недоступны до восстановления.

Следующая очередь: удаление непосредственно из строки списка; общий выбор чекбоксами; атомарное групповое перемещение в корзину; постановка выбранных задач в очередь через существующий QueueControl. Не удалять running, не скрывать ошибки отдельных задач, не выполнять массовые операции только в клиенте. SSE добавлять после защиты черновиков.
