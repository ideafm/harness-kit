# Устаревший worker и TASK-017

Скриншот TASK-017 сохранён, но запрос worker не содержит task_attachments:
процесс стартовал до обновления модулей. Перезапуск панели не перезапускает worker.

Добавить ревизию кода контроллера в worker.json. Перед стартом задачи сервис
сравнивает ревизии. Устаревший idle worker штатно завершается через worker.stop,
подтверждается освобождение lock, затем запускается актуальный процесс. Активную
задачу не прерывать: вернуть объяснение о необходимости дождаться завершения.
Новые worker сами завершаются при изменении кода между задачами. Без перезаписи
задач или снятия изоляции. Отдельно проверить native image аргумент адаптера.
