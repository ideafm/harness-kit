# npm run dev и отключение проектов

При init определять scripts.dev и сохранять npm run dev. Подготавливать локальные
установленные зависимости и Node в состоянии контроллера, не читать .env/.npmrc,
не устанавливать пакеты автоматически. Отсутствие node_modules объяснять явно.
Dev-server запускается в отдельной копии проверенного результата, под внешним
macOS sandbox с проверкой изоляции. Доступен только loopback, произвольная сеть и
доступ к исходному проекту/секретам запрещены. Установленные бинарники зависимостей
доступны npm через заново созданный .bin. Команда не интерполируется контроллером.
HTML, API приложения и WebSocket проходят локальный proxy; control endpoints
остаются у контроллера. Остановка завершает всю группу дочернего процесса.
Существующие start/stop/open, версия результата и ручная остановка сохраняются.

Удаление означает отключение от реестра, без удаления файлов/истории задач.
Поддержать удаление даже последнего/исходного проекта панели и пустой список.
Не отключать исполняющий задачи проект; объяснять необходимость остановки worker.
Останавливать принадлежащий контроллеру просмотр. HTTP требует Origin/CSRF,
актуальную ревизию реестра. Повтор удаления безопасен; старый запрос не удаляет
повторно подключённый проект. В UI явный диалог с названием и объяснением.
Работающую панель/worker этого репозитория не обновлять из исполняемого кода.
