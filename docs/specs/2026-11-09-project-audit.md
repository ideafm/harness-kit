# Аудит после переноса web — 2026-11-09

Поручение: изучить текущую реализацию, проверить интерфейс и исправить выявленные дефекты. Коммиты, приёмка задач и перезапуск рабочего контроллера не входят в этот проход.

Подтверждённый дефект: Runner.check использует scope задачи, а Next preview вычисляет digest и собирает корень workspace. Для scope web это разные исходники. Preview должен использовать тот же проверенный scope, отклонять отсутствующий каталог и символические ссылки, сохранять прежнее поведение задач без scope. Рабочий просмотр проекта должен сравнивать digest той же области.

Проверки: регрессионный тест scoped preview, основной Python suite, frontend tests/typecheck/build, просмотр существующей панели через Playwright без отправки операторских решений.

## Продолжение по поручению пользователя

Явное переключение исполнителя относится ко всей задаче: общее поле и все stage_backends переключаются на выбранный backend, предыдущие настройки записываются в событие. Модели не изменяются этим действием.

Обратимое удаление реализуется состоянием trashed. Сохраняются данные, артефакты, история и предыдущий статус. Running удалить нельзя. При восстановлении queued/rate_limited переходят в paused; остальные статусы восстанавливаются без запуска worker. Старые revision и подтверждения становятся недействительными. UI использует существующий идемпотентный транспорт команд и отдельный фильтр корзины. Отдельный frontend workflow Tw не запускается: это прямое поручение на доработку всего монорепозитория.
