# Автономный harness для Codex: первый проход

**Цель:** задача проходит исследование, спецификацию, план, реализацию,
проверки и независимое ревью без обязательного согласования каждого этапа.

**Результат:** CLI на Python без сторонних зависимостей, SQLite, один
исполнитель, изолированная рабочая копия, документы и журнал событий.

**Готово, когда:**

- Добавление задачи сохраняет исходный запрос; status показывает ожидания первыми.
- Планировщик сохраняет спецификацию и план; краткая сводка сохраняется и
  печатается до начала исполнения без ожидания подтверждения.
- Реализация не меняет исходную папку проекта. Проверки запускает контроллер,
  затем свежий ревьюер проверяет критерии. Ошибки возвращаются исполнителю
  ограниченное число раз; результат остаётся на приёмке у человека.
- Состояние этапа и попыток переживает перезапуск. Пауза и вопрос останавливают
  зависимую работу; ответ не расширяет права доступа.
- Ограничения доступа запрещают скрытые пути, env, ключи и credentials;
  сеть дочерних команд закрыта. MCP, браузер, плагины и эскалация отключены.
- Без успешной проверки песочницы запуск запрещён. Проверки также изолированы.
- Защищённые файлы не экспортируются из Git в рабочую копию, символические
  ссылки не экспортируются. Содержимое секретов контроллер не читает.
- Запрос защищённого действия сохраняется; разрешение может дать только
  человек. В первой версии доступ не открывается автоматически: пользователь
  выполняет согласованное действие вне агента и сообщает безопасный результат.
- Лимит Codex оставляет задачу в ожидании с временем следующей попытки;
  worker возобновляет готовые задачи. Неизвестное время использует backoff.
- Сценарные тесты проходят без платных запросов; реальный sandbox проверяется
  отдельно на безопасных canary-файлах.

**Не трогаем:** существующие `hooks/`, `scripts/`, `skills/`, глобальные
настройки и алиасы пользователя. Не переносим секреты и историю Claude.

**Не цель:** веб-интерфейс, автоматический merge, несколько исполнителей,
автоматическое предоставление SSH или доступа к секретам, установка пакетов,
производственный Linux до проверки эквивалентной изоляции.

**Допущения:**

- [допущение] Первый backend — локальный Codex CLI на macOS.
- [допущение] Рабочая копия создаётся из HEAD; незакоммиченные изменения
  исходного проекта не входят в задачу. Проверки задаёт человек при init.
- [допущение] Изоляция важнее удобства: скрытые конфиги и зависимости пока
  не копируются. Проектам с такими требованиями понадобится отдельная настройка.
- [допущение] Итог передаётся как diff и рабочая копия. Автоматическую
  интеграцию в основную ветку добавим после проверки первого прохода.
