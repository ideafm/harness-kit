# Вложения для Gemini

Сохранять исходные файлы в .harness/attachments и ссылки/hash в задаче.
Для agy CLI дать краткоживущую task-scoped проекцию изображений в отдельном каталоге --add-dir:
контроллер проверяет оригиналы, копирует в уникальный временный каталог вне исходников,
передаёт точные пути и требует открыть изображения через view_file.
Это допущение необходимо: headless stream-json принимает только text blocks,
а исходное хранилище содержит файлы других задач и не должно открываться целиком.
Не добавлять поддельные image blocks в транспорт.

Файлы проекции запрещены для записи permissions.deny независимо от стадии,
проверяются после вызова и удаляются до report/check/diff. При мутации — fail closed.
Каталог проекции не принимается в план изменений. Источник и метаданные не меняются.
SDK без подтверждённого image-tool контракта по-прежнему отказывает для изображений;
текстовые вложения работают как раньше. В UI убрать запрет изображений для Gemini CLI. Проверены image-tool контракты
agy 1.5.5/1.5.6; автообновление отключено только в окружении дочерних процессов.

Неявный lifecycle проекции: отсутствует → подготовлена → используется → проверена →
удалена. Выделить его в context manager; finally очищает и при ошибке/отмене.
Проектное .gitignore уже исключает .harness; глобальный ignore не изменяется.
Проверить fake transport/мутации/cleanup/scope, весь core suite и frontend build.
Живая проверка agy: синтетическая картинка с уникальным текстом + запреты записи и
чтения канареек. Не возобновлять реальные задачи ради smoke.
