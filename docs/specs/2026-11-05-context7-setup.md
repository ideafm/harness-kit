# Context7 для Codex

Запрос: подключить Context7 по https://context7.com/get-started.md.

Настройка глобальная: HTTP MCP `context7` по адресу
`https://mcp.context7.com/mcp/oauth`, правило использования документации и
навык Context7. Существующие MCP и инструкции сохраняются. Код Harness Kit,
его изоляция и legacy-компоненты не меняются.

Скрытые ресурсы доступны только после отдельного разрешения пользователя.
Чтение секретов не требуется. Вход OAuth пользователь выполняет сам командой
`codex mcp login context7`. Проверка документации: resolve-library-id для
Next.js, затем query-docs, когда сервер станет доступен в новой сессии.

Установщик: ctx7 0.9.0, Node.js >=22.13; локально Node.js 22.17.0.
