# Этап 2.1a: установка launcher и диагностика

Добавить tw install с выбором существующего bin-каталога в PATH либо явным
--bin-dir. Устанавливать только ссылки tw/tw-web на текущий контроллер;
чужие файлы не читать и не перезаписывать. Повтор установки идемпотентен.
Скрытые пути и ссылки в пути назначения отвергать. Shell-конфиги не менять.

tw diagnose работает до подключения проекта: показывает Python, Git, Codex,
launcher в PATH. Опциональная --sandbox выполняет существующий canary без
запроса к модели. Не менять смысл tw doctor подключённого проекта.
Это первая часть 2.1; единое подключение/автоопределение — следующая часть.
