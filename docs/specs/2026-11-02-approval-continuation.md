# Продолжение после утверждения

Утверждение плана в вебе уже вызывает service.start; отдельный запуск не нужен.
Проверено на TASK-003: plan_approved затем started и stage_started/implement.
Worker опрашивает очередь каждые пять секунд. Страница успешного подтверждения
должна явно говорить, что выполнение продолжится автоматически. Повтор той же
операции не должен повторять запуск worker. План, версия и guards сохраняются.
