# Подключение Context7

1. Прочитать официальную инструкцию и проверить Node.js — выполнено.
2. Получить разрешение на скрытые пути настройки — выполнено для config.toml
   и AGENTS.md в ~/.codex, а также для ~/.agents/skills.
3. Запустить `npx ctx7@latest setup --codex --mcp --oauth --yes`, сохранив
   существующие MCP и инструкции.
4. Проверить результат настройки без вывода секретов.
5. Передать пользователю команду входа; до загрузки MCP проверка документации
   остаётся pending. Коммиты и изменения runner не требуются.

Установка ctx7 0.9.0 завершилась успешно: MCP настроен с OAuth, правило
установлено в ~/.codex/AGENTS.md, навык — в ~/.agents/skills/context7-mcp.
Вход оставлен пользователю: `codex mcp login context7`. В текущей сессии
инструменты нового MCP ещё не доступны; проверка Next.js остаётся pending.
