# План редизайна веб-интерфейса tw-web на основе макета tw-web-design

## Контекст и цели
Интерфейс `tw-web` перерабатывается в соответствии с дизайн-макетом из архива `tw-web-design.zip` (интерфейс в духе Paperclip / современного agentic harness), сохраняя при этом все строгие требования безопасности, API-контракты (`lib/contracts.ts`), безопасный монтаж iframe `TrustedDecisionWidget` и прохождение всех frontend-тестов (`vitest run`).

## Анализ артефактов и требований

1. **Компоновка и навигация:**
   - **Левый сайдбар (`project-sidebar.tsx`):**
     - Двухуровневая структура: узкий dock rail слева (лого `tw` со статусом воркера, быстрые иконки действий/воркера/темы) + сворачиваемая панель проектов с поиском и пагинацией.
     - Устранение артефактов макета: убрать фиктивную иконку `hh` (из скриншота), отображать индикатор бэкенда (`Gemini` / `Codex`), кнопку создания задачи и подключение проектов.
   - **Верхняя панель (`Header.tsx` / `topbar`):**
     - Хлебные крошки с интерактивным дропдауном выбора проекта.
     - Индикаторы воркера, кнопка обновления с анимацией спиннера, кнопка быстрого создания задачи.

2. **Список задач (`task-table.tsx`):**
   - Компактный режим (высота строки 36–40px):
     - Чекбокс мульти-селекта (пакетные действия).
     - Номер `#num` (моноширинный).
     - Название задачи (однострочное усечение `truncate`).
     - 5-dot мини-индикатор фаз пайплайна (план, разработка, тесты, ревью, приемка).
     - Цветной статус-бейдж (`running` - синий/зеленый, `attention` - янтарный, `accepted_applied` - изумрудный с галочкой, `backlog` - нейтральный).
     - Кнопка быстрого удаления при наведении (hover).
   - Плавающая панель пакетных действий при выборе чекбоксами («Запустить очередь», «Удалить», «Снять выбор»).
   - Переключатель плотности (компактный / обычный) с сохранением aria-атрибутов для тестов.
   - Сохранение пагинации и поиска без сброса активной задачи в URL.

3. **Карточка задачи и детали исполнения (`task-card.tsx`, `PipelineStepper.tsx`, `ActionBanner.tsx`):**
   - **Пайплайн (`PipelineStepper.tsx`):**
     - 5 шагов: `План`, `Разработка`, `Проверки`, `Ревью`, `Приёмка`.
     - Математически связанная полоса прогресса, индикация статуса и времени выполнения шага.
     - Клик по шагу переключает соответствующую вкладку материалов.
   - **Блок действий (`ActionBanner.tsx`):**
     - Карточка «Что требуется от вас» с акцентным статусом.
     - Сворачиваемый блок «Подробности результата» (`<details><summary>`).
     - Интеграция безопасных действий оператора через существующий `TaskActions` / `TrustedDecisionWidget` (без обхода CSRF и iframe-изоляции).
     - Блок «Подробности применения» для принятых задач (короткий коммит, ветка, кнопка копирования git checkout).

4. **Вкладки материалов (`task-tabs.tsx`, `DiffViewer.tsx`):**
   - Стилизованные вкладки: `История`, `Исходная задача`, `План`, `Изменения`, `Проверки`, `Ревью`.
   - Поддержка счетчиков в бейджах вкладок (кол-во измененных файлов, проверок, логов).
   - Безопасный рендеринг исходного текста и артефактов без уязвимостей XSS (проверено тестами).
