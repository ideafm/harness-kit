# Оркестратор проекта — уточнённое направление

Пользователь уточнил: основные задачи поступают извне. Оркестратор управляет входящими задачами: декомпозирует, задаёт зависимости, распределяет исполнителей, отслеживает блокировки и результаты. Поиск новых проблем/предложений — отдельная команда по необходимости; автоматического обязательного пополнения бэклога при init нет.

При init можно создавать профиль проекта с целью, проверками, ограничениями и бюджетом. Оркестратор использует существующий scheduler и контроллерные политики, не создаёт конкурирующий LLM-планировщик и не получает право менять разрешения/самостоятельно принимать собственные результаты.

Очередность: UX приёмки/просмотра → явные зависимости задач → управление входящими задачами оркестратором → опциональная команда анализа проблем. Исполнители, независимый reviewer и разрешающая политика контроллера остаются отдельными ролями.
