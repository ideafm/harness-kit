# План

1. Серверный batch delete с атомарностью и идемпотентностью.
2. Общий выбор в списке и панель действий с подтверждением и pending.
3. Регрессионные тесты состояния/API/UI; core, frontend, tsc/build.
4. Проверенная публикация панели, перезапуск контроллера, browser smoke на тестовых данных, commit/push.

Реализация и проверки завершены: 259 core, 159 frontend, tsc/build успешны. Добавлены проверки атомарности при ошибке в середине группы, запрета running, stale revision, CSRF, повторных ключей, сохранения pending после remount и отмены отправки при смене проекта во время preflight. SSE оставлен вне этапа.
