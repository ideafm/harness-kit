# Реализация приёмки и зависимостей

1. Упростить trusted формы: accept одним нажатием, модалки feedback/reject с сохранением DOM; необязательный reject comment без ручного номера.
2. Свернуть preview-диагностику и второстепенные режимы; убрать недостоверные статусы.
3. Добавить неизменяемые depends_on при создании и допуск scheduler/Runner только после завершённого применения предпосылок; сохранить независимую очередь.
4. Тесты: 285 core, 167 frontend, tsc/build успешны. Проверить браузером реальное сохранение iframe при закрытии, компактную карточку и отсутствие лишних POST.

Направление оркестратора уточнено: управление входящими задачами; поиск проблем — отдельная команда. Новый демон/генератор не создавался. Изменение зависимостей уже созданной задачи — отдельный будущий этап с проверкой циклов; сейчас неизменяемые ссылки только на существующие номера исключают циклы по построению.

Публикация выполнена через проверенный integrated-build TASK-016; веб-контроллер и idle worker обновлены. Автоприменение осталось включённым. Browser QA: native dialog сохраняет тот же iframe и textarea при закрытии/открытии; родительских POST при этом нет, accept iframe имеет высоту 42 px. Живая карточка TASK-016 больше не показывает технические сведения старой задачи в основном блоке. Trusted submit блокирует повторное нажатие и показывает «Применяем…». Дополнительные 28 operator-тестов после изменения submit прошли. Реальные задачи не принимались/не отклонялись.
