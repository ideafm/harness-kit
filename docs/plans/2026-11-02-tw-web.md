# План итераций tw-web

**Статус:** каркас подготовлен; текущие шаги в [bootstrap](2026-11-02-bootstrap.md).
**Спецификация:** docs/specs/2026-11-02-tw-web.md

1. Общий сервис контроллера в harness-kit: структурированные операции и события,
   проверки состояний и разрешений. CLI остаётся рабочим. Проверка — сценарии
   CLI и будущего API используют одни переходы и блокировки.
2. Локальный каркас tw-web: HTTP-сервер, стартовая страница, команда тестов,
   обработка Origin/Host и запросов. Без подключения к выполнению агентов.
   Согласовать Git baseline и тестовое окружение.
3. Читающая панель: живые задачи, этапы, ожидания, документы, diff и проверки.
   Проверка — отображает реальные данные и не исполняет содержимое логов.
4. Управление: добавление задач, запуск, пауза, ответы, продолжение и приёмка
   через общий сервис. Проверка — закрытая вкладка не прерывает worker;
   повторный запрос не запускает второго исполнителя и не дублирует действие.
5. Развитие через собственную панель: небольшая задача UI проходит весь конвейер
   на tw-web. Подготовить интеграцию результата и сохранение предыдущей
   версии; права контроллера не расширяются из-за задачи интерфейса.
