# План

Продолжение после замечания ревью: сохранить имеющуюся реализацию; в project transport запретить проектные запросы для dot segments `.` и `..` с отклонённым Promise, не нарушая общий session. Добавить HTTP-тесты GET/POST без отправки и проверку нормализованного URL обычных id; interaction test должен проверить явную ошибку без чужих данных. Затем передать проверки текущего дерева контроллеру без локального запуска.

1. Сверить baseline и сохранить документы.
2. Добавить проектный transport, загрузку проектов, URL и защиту от поздних ответов.
3. Изолировать pending и компоненты, остановить polling при уходе.
4. Обновить sidebar, подключение и создание в выбранном проекте.
5. Добавить индикатор этапов каждой задачи и полировку.
6. Добавить mock tests, сохранив существующие проверки.
7. Передать TypeScript, interaction tests, production build и Python unittest контроллеру. Приёмку и применение оставить человеку.

По текущему поручению об исполнении сверены существующие файлы реализации и mock tests с пунктами 1–6. В этом продолжении уточнены только документы о границах текущего этапа.
