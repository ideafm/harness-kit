# План реализации v1

Человеческое утверждение и подготовка toolchain подтверждены переданным контекстом. Общий риск исходного плана high, объём large.

1. Сверить snapshot: исходный Python bootstrap, подготовленные package/lockfile и официальные shadcn; нового frontend нет.
2. Добавить видимые настройки статического Next export, Tailwind v4 и TypeScript без изменения зависимостей.
3. Реализовать русский интерфейс и typed /api/v1 transport: реальные задачи, свёрнутый запрос, артефакты и события, пустые и ошибочные состояния, мобильный sidebar.
4. Подключить обычные команды с CSRF/revision/идемпотентностью и опросом операции. Человеческие решения передавать отдельному confirmation origin, без POST из frontend и без фиктивного успеха.
5. Добавить interaction/transport tests с подставленным transport и jsdom. Сохранить исходные Python-тесты и launcher.
6. Передать контроллеру Python unittest, tsc --noEmit, vitest run, next build --webpack и подготовку receipt. После проверок контроллер связывает export с native gateway; агент не меняет соседний проект и не запускает preview.

Внешние prerequisites: готовность API и session/CSRF, проверенный Node sandbox, неизменяемые зависимости, безопасная раздача экспорта и независимый origin подтверждения. Эти части сообщены контроллером, но агент их не исследовал и не проверял.

Критерии сдачи: шесть вкладок, реальные данные и явные ошибки, сохранение ввода при polling, раздельные решения по результату, точный confirmation origin, обязательный GET операции перед успехом, лимиты UTF-8, отсутствие изменений dependencies/Python lifecycle. Проверки и visual/mobile QA должны быть подтверждены контроллером. Результат не принимается и не применяется автоматически.

Исправление после контроллерной сборки: TaskPanel вынесен из экспортов app/page в разрешённый модуль components/task-table; тест импортирует компонент оттуда. Создание использует подтверждённый контракт 201 {task,revision}, выбирает созданную задачу; операции действий по-прежнему требуют опроса. Учитываются accepted и stage done, а также начальный ?task=ID. Новые файлы и зависимости не добавлены. Node-проверки выполняет только контроллер; эта итерация не заявляет успешную сборку.

Исправление по независимому ревью: сверена существующая реализация; сохранён действующий confirmation origin. Дополнен блок решений для waiting с вопросом и review. Повтор неопределённой команды использует сохранённые тело, revision и ключ независимо от polling; после получения operation_id выполняется только проверка операции. Окончательный HTTP-отказ освобождает команду. Добавлены регрессионные сценарии для этих случаев и перехода после 409. Проверки Python, TypeScript, Vitest и Next в этой итерации агентом не выполнялись; следующий шаг — controller_check и frontend-проверки в подготовленной копии. Покрытие mobile/keyboard по-прежнему требует отдельной проверки контроллером.

Продолжение по ревью: после сверки компонентов добавлено сохранение неопределённых команд и создания в sessionStorage. Добавлены регрессии remount/reload, восстановления operation_id, исправленного ввода после 400/422 и режима auto. Добавлены interaction-сценарии навигации по вкладкам стрелками, мобильного Sheet и возврата фокуса после Escape. Исходные тесты сохранены. Node и проверки контроллера не запускались; визуальная читаемость требует проверки в подготовленном браузерном sandbox контроллера.
