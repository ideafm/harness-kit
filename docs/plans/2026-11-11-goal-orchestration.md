## Реализация

Git merge-tree строит кандидат без изменения основной копии; безопасный snapshot
проходит штатный sandbox/toolchain. Применяется merge commit проверенного дерева.
Receipt и лог сохраняются отдельно от исходной проверки задачи. Повторная проверка
не стартует при ещё живом процессе предыдущей попытки. Ошибки блокируют зависимых.

goals.py хранит исходный запрос/критерии и связи в контроллерной SQLite.
CLI/MCP поддерживают постановку, просмотр, повторную итоговую проверку; Tw skill
использует эти операции. Общий статус вычисляется из задач и актуального дерева main.
Итоговая задача не может попасть на implement; pass ждёт человека. Подзадачи
сохраняют существующие правила риска, согласования и автоприменения.
