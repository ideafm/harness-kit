## Журнал

- 2026-11-02 · Начата реализация знакомого входа Tw; runtime-контроллер
  сохраняется за интерфейсом skills/MCP. Глобальные настройки не меняются.
- 2026-11-02 · Добавлены bin/tw, локальный skill и ограниченный stdio MCP.
  init сохраняет инструкции и задачи, проверяет принадлежность файлов и
  отказывается перезаписывать ручные изменения. Приёмка и grants не доступны MCP.
- 2026-11-02 · Taskboard подключён; повторный init проверен. Существующая
  TASK-001 осталась review/done и не принята за пользователя. Для helper apply
  допускаются только неизменённые setup-файлы с проверенными точными путями
  и SHA-256; любые другие изменения исходника по-прежнему блокируют применение.
- 2026-11-02 · Настоящий Codex прочитал skill и вызвал MCP tw_status. Затем
  tests/codex/live_tw_smoke.py подтвердил весь путь: чат поставил одну задачу
  и завершился; внешний worker выполнил план, реализацию, проверки и ревью,
  исходник остался прежним. Тестовый worker штатно остановлен после проверки.
- 2026-11-02 · Полный прогон выявил попытку worker читать AGENTS из родительского
  исходного проекта. Автозагрузка этих инструкций отключена только в worker;
  инструкции передаются из AGENTS.md в snapshot. Собственный gateway skill
  отключён для этапов worker, чтобы не было вложенной постановки задач.
  Расширения файловых прав и unrestricted fallback не добавлены.
- 2026-11-02 · 60 unit/scenario tests зелёные. Проверка YAML метаданных и
  frontmatter выполнена системным Ruby YAML. Bundled quick_validate.py был
  запущен, но недоступен из-за отсутствующего PyYAML; зависимости не ставились.
  Синтаксис и поведение skill дополнительно проверены настоящим Codex.
- 2026-11-02 · Внешние операции используют текущие переходы CLI; добавлена
  CAS-защита answer/resume/accept. Worker удерживает существующую блокировку,
  статус проверяет её, а tw stop ставит задачу на паузу и просит worker выйти.
- 2026-11-02 · README, инструкция Taskboard и инструкция Web Harness обновлены.
  Для короткой команды достаточно добавить bin в PATH текущего терминала.

  основного проекта нет. Web Harness остаётся неподключённым до каркаса и Git baseline.
