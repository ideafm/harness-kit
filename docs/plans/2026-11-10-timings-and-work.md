# План

1. Вычислить время по событиям в API, убрать фиктивные времена в UI.
2. Добавить «В работу» для backlog через существующие очередь и транспорт команд.
3. Регрессионные тесты, core/frontend/tsc/build, проверенная публикация и commit/push.
4. Ночной режим и явные зависимости реализовать отдельным этапом; независимая очередь не останавливается из-за одной задачи.

Реализованы реальные времена по журналу и «В работу» в карточке backlog; порядок очереди не менялся. Для ночного режима создана отдельная спецификация docs/specs/2026-11-10-night-mode.md с независимыми задачами и depends_on. Реализация ночного режима не начиналась.

Проверки: 264 core, 162 frontend, TypeScript и production build успешны. Времена старых задач вычисляются из сохранённого журнала без их перезапуска. Повтор enqueue с тем же ключом не меняет очередь повторно и не запускает второй worker.
