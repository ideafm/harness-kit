# Варианты интерфейса Tw

Открыть локальную галерею: http://127.0.0.1:47839

- A «Фокус»: http://127.0.0.1:47839/?variant=focus
- B «Очередь»: http://127.0.0.1:47839/?variant=queue
- C «Лента»: http://127.0.0.1:47839/?variant=feed

Все варианты находятся в одном автономном index.html. Его можно сохранить
и открыть локально без установки зависимостей и без сети. Для локальной раздачи:
python3 -B docs/designs/tw-ui/serve.py из harness-kit. Порт фиксирован, только
loopback, сервер отдаёт только index.html; все POST запрещены.

Это дизайн-макет с явно обозначенными демонстрационными данными и действиями.
Никаких вызовов контроллера, настоящих приёмок, очередей или сообщений агенту.
Переключатели показывают композиции, статусы, причины остановки, модалки,
worker и принятие внутри карточки. Этапы доступны с клавиатуры и показывают
подсказки. Иконки — собственные SVG, без библиотеки. Рабочее приложение после
выбора направления сохраняет shadcn-компоненты; макет написан без зависимостей.

Проверено выполнение JS и взаимодействия через jsdom в подготовленном Node
sandbox. HTTP smoke подтвердил содержимое, запрет других файлов/POST и CSP
без сетевых запросов. Попытка headless Chrome в ограниченном sandbox завершилась
ошибкой, вне sandbox Chrome не запускался. Визуальная компоновка и размеры
в настоящем браузере автоматически не подтверждены. TASK-004 не возобновлялась.
